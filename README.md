# TrackFix / GPX

Редактор геометрии велотрека в браузере — https://wild-loop.ru

Загружаете запись заезда (GPX, FIT или TCX), находите участок, где GPS «срезал» маршрут или улетел в сторону, и исправляете только геометрию: время, высота, пульс, мощность и каденс сохраняются. Результат выгружается в GPX, который принимают Strava, Garmin Connect и другие сервисы.

Файл разбирается и редактируется локально в браузере и никуда не загружается. В сеть уходят только координаты правимого участка — для построения маршрута по дорогам и запроса высот рельефа.

## Возможности

- **Анализ**: дистанция, время в движении, набор/спуск, средняя и максимальная скорость, мощность, пульс, каденс, калории; темп по километрам.
- **Диагностика**: автоматический поиск GPS-сбоев (скорость выше 65 км/ч или скачок между точками) и пауз.
- **Трек-лайн**: высота, скорость, пульс и мощность; выделение промежутка протягиванием мышью.
- **Правка**:
  - вырезать участок;
  - перерисовать по карте: по прямым, по велодорогам OSM (FOSSGIS OSRM) или от руки. Параметры можно растянуть по новой длине или интерполировать;
  - «Точки» — правка выбросов прямо на карте. Показаны все точки выделенного участка, выбросы закрашены. Точку можно перетаскивать с живым предпросмотром или двигать стрелками на 1 м (с Shift — на 10 м). Новая точка — через «+» между точками или клик у линии. Удаление — двойной клик, правая кнопка или Delete. Есть кнопка «Удалить выбросы»;
  - сгладить GPS-шум;
  - пересчитать высоту по DEM (open-meteo / Copernicus, запасной вариант — open-elevation);
  - обрезать начало и конец;
  - разделить трек и склеить части (или добавить второй файл);
  - сдвинуть время старта и удалить паузы.
- Отмена любого шага (Ctrl/⌘+Z).
- Экспорт в трёх форматах:
  - **GPX 1.1** — с Garmin TrackPointExtension и `<power>`;
  - **TCX** — Training Center v2: трек с пульсом, каденсом, скоростью и мощностью, сводка круга;
  - **FIT** — двоичный файл активности: записи, события, круг, сессия, activity, контрольные суммы CRC. Strava и Garmin Connect принимают его как запись с устройства.

## Автопоиск выбросов

Правила лежат в `app/config/detect.json` — это значения по умолчанию для всех посетителей:

| Ключ | Что делает |
|---|---|
| `showOnMap` | подсвечивать найденные выбросы на карте оранжевым |
| `speed.maxKmh` | отрезок между точками быстрее порога — телепорт или потеря сигнала |
| `jump.maxM`, `jump.vsMedian` | один шаг длиннее N м или в K раз длиннее типичного — разрыв записи |
| `spike.minM`, `spike.maxAngleDeg` | точка улетает в сторону и сразу возвращается: оба плеча длиннее N м, угол при точке меньше N° |
| `mergeGapPoints` | выбросы через ≤ N чистых точек объединяются в один участок |
| `pause.maxKmh`, `pause.minSec` | что считать стоянкой: время в движении, полосы пауз, «Удалить паузы» |

У каждого правила есть `enabled`. Каждый посетитель может подстроить правила под себя в «Диагностика → Настроить». Изменения применяются сразу и сохраняются в его браузере, там же можно сбросить их или скачать как JSON. Скачанный файл можно положить на место `detect.json` и выложить — тогда эти правила станут значениями по умолчанию для всех.

Найденные выбросы подсвечиваются на карте оранжевым пунктиром, точки внутри выброса отмечены кружками. При наведении видна причина, клик выделяет участок и открывает перерисовку.

```
  index.html
  css/industry.css      дизайн-система Industry

  js/parsers.js         GPX / TCX / FIT

```

## Локальный запуск

```bash
python3 -m http.server 8765 --directory app
```

Затем откройте http://localhost:8765. Демо-трек загружается по адресу http://localhost:8765/?demo.

## Docker

```bash
docker compose up -d --build
```

Caddy раздаёт сайт на :80 по любому хосту и сам получает HTTPS-сертификат для `SITE_DOMAIN` (по умолчанию `wild-loop.ru`), как только A-запись домена указывает на сервер. Другой домен можно передать так: `SITE_DOMAIN=example.com docker compose up -d`.

```bash
./deploy.sh root@77.105.142.193
```
